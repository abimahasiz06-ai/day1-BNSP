 Day 1 BNSP — Belajar Dasar HTML

1.Deskripsi Pembelajaran
Repository ini berisi hasil pembelajaran hari pertama dalam pelatihan BNSP. Pada pembelajaran ini, saya mempelajari dasar-dasar HTML untuk membuat struktur halaman website sederhana.
Project ini dibuat sebagai langkah awal untuk memahami bagaimana sebuah website disusun menggunakan HTML, mulai dari bagian judul, paragraf, daftar, tautan, hingga bagian penutup halaman.

2.Tujuan Pembelajaran

- Memahami struktur dasar dokumen HTML.
- Mengenal berbagai tag HTML dan fungsinya.
- Membuat halaman website sederhana.
- Menampilkan informasi dalam bentuk teks dan daftar.
- Membuat tautan menggunakan tag HTML.
- Mengenal dasar pengembangan website sebagai persiapan mempelajari CSS, JavaScript, dan teknologi web lainnya.

3.Materi yang Dipelajari

  1. Struktur Dasar HTML
  Memahami struktur dokumen HTML yang terdiri dari `<!DOCTYPE html>`, `<html>`, `<head>`, dan `<body>`.

  2. Heading dan Paragraf
  Menggunakan tag `<h1>`, `<h2>`, dan `<p>` untuk menampilkan judul, subjudul, dan paragraf pada halaman website.

  3. Pengelompokan Konten
  Mempelajari penggunaan tag `<header>`, `<main>`, `<section>`, dan `<footer>` untuk menyusun konten website agar lebih terstruktur.

  4. Membuat Daftar
  Menggunakan tag `<ul>` dan `<li>` untuk membuat daftar tidak berurutan, serta `<ol>` dan `<li>` untuk membuat daftar berurutan.

  5. Membuat Tautan
  Menggunakan tag `<a>` dengan atribut `href` untuk mengarahkan pengguna ke halaman atau alamat website tertentu.

  6. Pengaturan Informasi Halaman
  Mengenal tag `<title>` untuk menentukan judul halaman browser, `<meta charset="UTF-8">`untuk mendukung karakter teks, serta `<meta name="viewport">` untuk membantu tampilan menyesuaikan ukuran layar perangkat.
  8. Menampilkan Copyright
  Menggunakan tag `<footer>` dan karakter khusus `&copy;` untuk menampilkan informasi hak cipta pada bagian bawah halaman.

4.Teknologi yang Digunakan

- HTML — untuk membuat struktur halaman website.
- Visual Studio Code — sebagai editor kode.
- Git — untuk mengelola versi kode.
- GitHub — untuk menyimpan dan mendokumentasikan hasil pembelajaran.

5.Hasil Pembelajaran
  Hasil dari pembelajaran ini adalah sebuah halaman website sederhana yang memiliki beberapa bagian:

- Header yang berisi judul dan deskripsi singkat.
- Bagian Tentang Saya.
- Daftar teknologi yang sedang dipelajari.
- Daftar target pembelajaran.
- Bagian kontak yang menggunakan tautan.
- Footer yang menampilkan informasi copyright.

6.Cara Menjalankan Project

1. Unduh atau clone repository ini.
2. Buka folder project menggunakan Visual Studio Code.
3. Buka file `index.html` menggunakan browser seperti Google Chrome atau Microsoft Edge.
4. Halaman website akan ditampilkan di browser.

7.Kesimpulan

Melalui pembelajaran hari pertama ini, saya memahami dasar penggunaan HTML untuk membangun struktur halaman website. Saya juga belajar bahwa setiap tag HTML memiliki fungsi yang berbeda dalam menyusun konten.
Pembelajaran ini menjadi fondasi untuk mempelajari CSS dalam mengatur tampilan website dan JavaScript untuk menambahkan interaksi pada halaman web.
